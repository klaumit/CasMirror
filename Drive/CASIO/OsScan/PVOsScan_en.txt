PVOS-Scan Program.
~~~~~~~~~~~~~~~~~~~~
Scans a BIN file to parse the modules contained within it.
Header parameters are displayed for each module.
Module names and icon addresses are not shown, as these fields are typically
empty for modules within the OS image.
OS module names must be identified via their mode-submode field
(this feature is not yet implemented but is planned).
BIN collections can also be viewed.
Most values ​​in the table are in hexadecimal format.
The allocation table can be saved to a text file.

Note:
~~~~~~
The "128KB" flag is intended for OS files that lack the
first 128KB bank (the BIOS). Enabling it simply adds 2 × 64 × 1024 = 128KB
to the values ​​in the first column.
(It sometimes glitches for some reason—simply toggle it off and on again).
Files existing in this format (BIN file without BIOS) include:
APPLALL.BIN – the PVOS module file for the emulator,
PVOS.DAT – the module file from the SSC-OS XP-2 distribution
(actually, this is just a standard APPALL.BIN without the tables module).

Note:
~~~~~~~
A PVOS file can be larger than 1 MB; in that case, it simply
contains add-ins that will be located in the program area.
In this sense, the first 2 megabytes of Casio PV memory can be viewed
as a continuous program area.
It loads into the emulator as a single file without issues; you simply
need to assign submode sequence numbers (starting from 01) to the add-ins.
