LSB<->MSB convertor; Copyright (c) 2004 by O'Razoff. V1.0

Программа предназначена для перекодировки двоичных файлов из формата LSB
(Little endian) в MSB (Big endian) и/или обратно.

Запуск программы:

l2m [-s] [-a] [-w] file.in file.out
-s strip 16-bytes head [no]
-a add 16-bytes head [no]
-w word alignment [long]

Имеется в виду, что file.in - входной файл, а file.out - выходной.
Ключи опциональны, то есть можно программу запустить так:

l2m file.in file.out

В этом случае входной файл преобразуется в выходной с выравниванием на длинное
слово (4 байта), удаления/добавления заголовка не производится.


Описание ключей программы.

Ключ -S (Strip) удаляет первые 16 байт входного файла (заголовок файла PV OS
эмулятора PV-S1600, для которого изначально и написана эта программа) и имеет
смысл только при преобразовании файла эмулятора (CasioNAND.mem) в двоичный файл
для анализа. Пример использования ключа:

l2m -s CasioNAND.mem pvos_sim.bin


Ключ -A (Add) добавляет в выходной файл заголовок PV OS эмулятора PV-S1600,
(для которого изначально и написана эта программа) и имеет смысл только при
обратном преобразовании двоичного файла с образом PV-OS 1600 в файл эмулятора
(CasioNAND.mem) Пример использования ключа:

l2m -a pvos_sim.bin CasioNAND.mem


Ключ -W (Word alignment) устанавливает выравнивание данных на слово (2 байта).
Это значит, что если во входном файле порядок байтов был 1234, то в выходном
будет 2143. По умолчанию данные считаются выравненными на длинное слово (4
байта), то есть если во входном файле порядок байтов был 1234, то в выходном
будет 4321. Пример использования ключа:

l2m -w file.in file.out


Сообщения программы.

Если программа завершается нормально, никаких сообщений не выдается и
создается выходной файл. Могут иметь место следующие сообщения:

I/O error.	- ошибка чтения/записи файлов.

В случае указания неверных параметров появляется следующее сообщение:

l2m [-s] [-a] [-w] file.in file.out
-s strip 16-bytes head [no]
-a add 16-bytes head [no]
-w word alignment [long]
